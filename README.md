# TRUST-ICU

**Transportable and Risk-Controlled Prediction of Acute Organ-Support Escalation Across Multiple ICUs**

This repository hosts a preregistered, leakage-aware, multi-database ICU prediction study. Development work is performed on feature branches. No restricted patient-level data, derived row-level cohorts, model weights trained on credentialed data, or secrets may be committed to this public repository.

Current status: repository initialized; Phase 0 feasibility protocol in development.
